## 1. 核心对象定义（Core Model）

* **一句话描述**：借鉴空间站刚性太阳能翼的四连杆折叠机制，打造集 22cm 极致收纳、38cm 宽阔展开击杀面、物理无软线触点安全互锁、5000mAh 户外反向供电及战术手电于一体的硬核 EDC 驱虫装备。
* **主要解决痛点**：加拿大埃德蒙顿及北美夏秋林区凶猛蚊潮下，传统电蚊拍体积过大无法携带、化学驱蚊在河谷风力下失效、折叠电器软线弯折易短路起火的行业难题。
