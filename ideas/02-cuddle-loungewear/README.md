## 1. 核心对象模型（Core Model）

* **一句话陈述**：首款将“背侧双向力学悬桥手臂减压架构”与“隐形双舱防漏风触控门襟”结合的高街慵懒风多功能家居服。
* **解决痛点**：
  1. **手臂重压问题**：情侣侧卧拥抱时，男方 4kg 手臂长期压迫女方侧肋与胸腹，造成胸闷疼痛；
